# Лабораторная работа №1: клеточный автомат

Двумерный бинарный клеточный автомат с окрестностью фон Неймана,
тороидальными границами и правилом `55 518 056`. Все клетки меняют состояние
синхронно. Графический интерфейс написан на Qt 6.

## Сборка и запуск

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt@6
cmake --build build
ctest --test-dir build --output-on-failure
./build/cellular_automaton
```

В интерфейсе можно задать размер квадратного поля и число итераций, заполнить
поле случайно с выбранной ожидаемой плотностью либо вручную кликами мыши, выполнить
один или несколько шагов и запустить непрерывную анимацию. Селектор пресетов
загружает четыре характерных режима поведения: неподвижный, периодический,
хаотический и сложный локализованный.

## Правило перехода

При создании автомата номер правила переводится в явную таблицу истинности из
32 элементов. Пять битов окрестности имеют лекционный порядок `центр, верх,
низ, лево, право` и образуют номер строки `k` от 0 до 31. Новое состояние читается из этой
строки таблицы:

```text
truthTable[k] = (55 518 056 >> k) & 1
next = truthTable[k]
```

Класс `CellularAutomaton` не зависит от Qt. Интерфейс изменяет модель только
через публичные методы (`setCell`, `toggleCell`, `randomize`, `step`, `run`) и
читает состояние через `cell`, `cells`, `size` и `generation`.
