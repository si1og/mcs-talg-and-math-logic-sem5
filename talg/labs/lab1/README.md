# Лабораторная работа №1: клеточный автомат

Двумерный бинарный клеточный автомат с окрестностью фон Неймана,
тороидальными границами и правилом `55 518 056`. Все клетки меняют состояние
синхронно. Графический интерфейс написан на Qt 6.

## Сборка и запуск

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt@6
cmake --build build
ctest --test-dir build --output-on-failure
./build/cellular_automaton
```

В интерфейсе можно задать размер квадратного поля и число итераций, заполнить
поле случайно с выбранной вероятностью либо вручную кликами мыши, выполнить
один или несколько шагов и запустить непрерывную анимацию.

## Правило перехода

Пять битов окрестности имеют порядок `верх, лево, центр, право, низ` и образуют
число `k` от 0 до 31. Новое состояние равно биту `k` числа `55 518 056`:

```text
next = (55 518 056 >> k) & 1
```

Класс `CellularAutomaton` не зависит от Qt. Интерфейс изменяет модель только
через публичные методы (`setCell`, `toggleCell`, `randomize`, `step`, `run`) и
читает состояние через `cell`, `cells`, `size` и `generation`.
